# 螢光底色分類器（網頁版）

把 Word（.docx）裡**底色相同**的文字，依原順序放在一起。只搬動，不改字、不刪字。

**不用安裝、不用註冊、檔案不離開你的電腦。** 打開網頁，把檔案拖進去，下載結果。

## 使用
1. 打開網頁（部署後的連結放這裡），或下載 `index.html` 用瀏覽器直接開，離線也能用。
2. 選擇依什麼分類：螢光筆底色（預設）、底紋、字型顏色。
3. 把 .docx 拖進虛線框，可一次多個檔案。
4. 看到 ✅ 後按「下載 檔名_分類.docx」。

結果檔：每個顏色一個標題（顏色＋字數），組內文字照原順序，保留原本的顏色；沒有顏色的字放在最後一組。

## 為什麼可以信任
- **檔案不會被送出去。** 整個程式就是 `index.html` 一個檔案（約 30 KB，可用文字編輯器完整讀完）。頁面內建 `connect-src 'none'`，瀏覽器會擋下它發出的任何連線；按頁面上的「測試連線」就能親眼看到被擋下。你也可以先斷網再使用。
- **不依賴任何外部程式庫、字型或 CDN。** 解壓縮與壓縮用瀏覽器內建功能。
- **每次處理都做 5 項檢測**，任何一項不過就不提供下載：
  1. 字數守恆：分組後的總字數 = 原文總字數（用另一條路徑重新計數）
  2. 編號不重複不遺漏
  3. 依原始編號排回去，與原文逐字一致
  4. 重新讀取產出的 Word，各組內容與預期一致
  5. 產出檔裡每個字的顏色都在對的組
- **自我測試**：頁面下方「執行自我測試」會產生隨機文件、處理後與標準答案逐字比對，並故意刪掉一個字確認檢測抓得到。
- **兩套獨立實作互相驗證**：`python/` 是同一演算法的 Python 版；`tests/` 用同一批文件確認兩邊輸出逐組逐段完全一致。

## 限制
- 只讀 .docx 的**文字層級**顏色（螢光筆、底紋、字型顏色）。段落底色、表格儲存格底色、由「樣式」帶來的顏色不會被讀到；這類文字會歸入「無顏色」，頁面會在無顏色超過 50% 時提醒你。
- 舊格式 .doc 請先另存成 .docx。
- 文字方塊、追蹤修訂的內容有處理，但尚未在大量真實文件上驗證。
- 瀏覽器需要支援 `CompressionStream`（Chrome／Edge 103+、Safari 16.4+、Firefox 113+）。
- 實測：200 萬字約 4 秒（Chromium，一般筆電等級）。

## 部署到 GitHub Pages（三步）
1. 把這個資料夾的內容放進一個新的公開倉庫（根目錄要有 `index.html`）。
2. 倉庫 Settings → Pages → Source 選 *Deploy from a branch*，Branch 選 `main`、資料夾 `/ (root)`，儲存。
3. 約一分鐘後，網址是 `https://<帳號>.github.io/<倉庫名>/`。

## 開發與測試
```
# 自我測試：開網頁按「執行自我測試」
# 跨實作比對（需要 Python 3、python-docx、Node、Playwright）
pip install -r python/requirements.txt
python3 tests/make_samples.py /tmp/samples
node tests/web_run.js index.html /tmp/web /tmp/samples/mixed.docx /tmp/samples/large.docx
python3 tests/compare.py /tmp/samples /tmp/web
```
